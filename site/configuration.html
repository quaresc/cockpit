Configuration

~/.config/cockpit/config.json, written by /cockpit:setup, re-read every 30 seconds. /cockpit flips what you change day to day.

Where data comes from

The hub fetches GitHub every minute with gh's token (or GH_TOKEN), so PRs and checks stay fresh without a Claude session. Everything else comes through a session's connectors, unless you give the hub a token: tickets.token (a Linear API key) or ci.token (a CircleCI personal API token). Tokens stay in this file only.

Keys

Key
reposDirWhere your checkouts live; new agent spaces start there.
github.orgOnly list your PRs from this org.
ticketsTicket connector: server, keys (prefixes such as ENG), urlTemplate, and the mapping for anything but Linear.
tickets.tokenOptional Linear API key (Settings → Security & access): the hub fetches tickets itself.
ciGitHub checks when server is empty, else a CI connector and its mapping. imageJob: the job that builds a preview's image.
ci.tokenOptional CircleCI personal API token: the hub fetches runs itself.
calendarGoogle Calendar, or another connector and its mapping.
platformDeploy and preview connector, and its mapping: previewPrefix (how a preview's id starts), previewDashboardUrl (with {preview}), workflowUrl (with {namespace} and {name}), tools and fields.
metabase, datadogConnectors for live panes; Datadog also feeds the monitor.
monitorenv; the Datadog queries per service (errors, hits, p95, with {service} and {env}); when a release counts as moved (errorPoints, p95Ratio, p95Ms, minHits); whose releases notify (mine, all, none).
brief, meetingBrief, recap, deployWatchWhen they run and which tools they may use.
agents.recapauto (default): an agent's recap is asked of haiku a minute after its turn ends, when nobody looked at it; manual: only when you ask.
e2eBrowserterminal-browser (beside the agent) or chrome (Claude in Chrome).
browserIdleMinutesA browser beside an agent whose space stayed out of view this long closes, to stop it drawing; 0 keeps it.
spacesPinned spaces in sidebar order. See below.
runbookToolsExtra tools the background runbook refresh may use, e.g. a read-only database MCP.
worktreestrue: the inbox opens a branch checked out nowhere in a new herdr worktree instead of the main checkout.
densitycomfortable (default, actions in a panel under the list) or compact (buttons on the row). /cockpit switches it.
editorThe editor Open in editor uses: code (default), cursor, zed, or any command that takes a folder.
herdrPluginRootLeft empty: cockpit finds the herdr plugin in herdr's registry, which follows its updates.

Pinned spaces

spaces lists the pinned spaces in sidebar order: inbox, terminal, actions (a tab per review, plan or talk started from the inbox or runbook), to-do, runbook, meetings, the opt-in monitor and routines, and your own, as a name or an object:

"spaces": ["inbox", "terminal", "actions", "to-do", "runbook", "meetings", "routines",
           { "name": "notes", "cwd": "~/notes", "icon": "", "key": "prefix+n" }]

icon is a Nerd Font glyph, key a free prefix+<letter>. An open space with that name becomes the pinned one.

Routines

Each routine is a file in ~/.config/cockpit/routines/: key: value lines between two --- lines, then the prompt Claude runs (or the script, with run: shell). /routine <when and what> writes one for you, a in the routines space adds one in a form.

---
name: Morning sweep
when: weekdays 09:00
model: sonnet
tools: Read, Grep, Bash(gh pr list:*)
notify: failed
---

Sum up my open PRs: which wait for review, which fail CI, which can merge.
Key
whenmanual, every 30m (or 2h, 1d), hourly, daily 09:00, weekdays 9:00,17:30, weekends 10:00, mon,thu 14:00, tue-fri 08:15, cron <minute hour day month weekday>, or on <trigger> [words]. Triggers: review, approved, changes, opened, merged, ci-failed, ci-passed, ticket, assigned, live, release, release-ok, release-moved, release-failed, alert, error, any. Times are local.
cwdWhere it runs. Left out, a Claude routine runs in a folder of its own, so no project's CLAUDE.md or memory is read.
run: shellRuns the body with sh -c instead of Claude, with $COCKPIT_EVENT, $COCKPIT_EVENT_KEY and $COCKPIT_EVENT_KIND when an event set it off.
modellightest (haiku at low effort, nothing loaded but the tools it lists: the cheapest run), haiku, sonnet, opus, or left out for your default.
toolsComma-separated allow rules, MCP tools by their full mcp__… name.
budgetDollars a week, as Claude estimates its runs. Runs wait once the week's runs reach it.
timeout · notify · pausedMinutes (30 by default) · always, failed or never · true to pause it.
