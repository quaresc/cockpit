How it works

From install to one place, in three steps

  1. Install

    Two commands, in Claude Code or a shell. Setup picks your agent and features and wires herdr, the Herdr app, or both.

  2. Agents get context

    Each session knows its ticket, branch, PR, CI and deploy, and shows them right beside it.

  3. Work from one place

    Home says who waits on you. Answer, merge, fix CI or recap without hunting for the tab.

Install

Two commands

Setup asks what you want, writes your config and installs both halves.

  • macOS or Linux, with gh signed in and jq
  • herdr 0.9+ (with a Nerd Font), the Herdr app, or both
  • Any agent Herdr runs; tickets, PRs, CI, meetings, mail and deploys from the MCP servers you already use
Claude Code 
> /plugin install cockpit --marketplace quaresc/cockpit
> /cockpit:setup
# any time later
> /cockpit:doctor
> /plugin update cockpit@cockpit
shell, for any other agent 
$ curl -fsSL https://raw.githubusercontent.com/quaresc/cockpit/main/install.sh | sh
$ cockpit setup
# any time later
$ cockpit doctor
$ cockpit update

/cockpit:doctor or cockpit doctor checks every part and fixes what is broken. A notification tells you when a new version is out; a click, or cockpit update, updates every part.

FAQ

Questions

Do I need API tokens?

No. GitHub goes through your gh login. Tickets, CI, meetings, deploys and the release monitor come from MCP servers: cockpit calls them itself, with any agent. Setup finds the ones your agents already use, logs cockpit in once through your browser, and has your agent map a server cockpit does not know yet.

In Claude Code, cockpit can use its connectors instead, through one hidden, idle session the hub keeps.

What does it cost?

cockpit is free and MIT-licensed. What it asks an agent to do runs on your own agent's plan: recaps, meeting briefs, and routines, which take a weekly budget. Each one can be turned off.

Reading your MCP servers costs nothing: cockpit calls them itself, and the hidden Claude Code session some setups keep sits idle at its prompt.

Does it work without the Herdr app?

Yes. The herdr half works alone in your terminal, the Herdr app half works alone, and both can run at once on the same hub. Setup wires whichever you have.

Is my data sent anywhere?

Not to cockpit: there is no cockpit server. The hub runs on your machine, listens only on 127.0.0.1 with a token, and keeps its state in ~/.cache/cockpit.

It talks to GitHub, your ticket and CI tools and your calendar as you, and agent features go through your own agent. Search over past sessions uses a small model, downloaded once and run locally.
