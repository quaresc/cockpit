cockpit

One space with everything, for Claude Code users who switch context all day.

A Claude Code plugin and a herdr plugin that work as one, also drawn natively in the Herdr desktop app.

Install See the features GitHub

What it adds

herdr runs your agents side by side but doesn't know what they work on. cockpit adds that context:

Beside each agent

Each agent sits beside its ticket, PR, CI, deploy and the page it tests.

Pinned spaces

Your inbox, runbooks, to-dos, meetings, releases and routines, one key away.

One palette

Searches all of it, the week's history and your past sessions.

Install

In a Claude Code session inside herdr:

/plugin install cockpit --marketplace quaresc/cockpit
/cockpit:setup

Setup installs the herdr half for your machine, asks which features you want and writes your config. /cockpit:doctor checks everything and says how to fix it. Updates arrive as a notification.

Needs macOS (Linux untested), herdr 0.9+, gh signed in, jq, Xcode command line tools and a Nerd Font.

Two places to run it

Both halves run on the same hub and the same data, and can run at once.

In herdr, the terminal

A sidebar, a footer of links under each agent, pinned spaces with their apps, and a palette over any pane.

The herdr half

In the Herdr app

Drawn natively by the Herdr desktop app. /cockpit:setup installs it when the app is there (or run cockpit app install), and the window switches once to the cockpit layout (⌘⇧L switches layouts).

The Herdr app

Through Claude Code

The plugin fetches from your sessions' connectors and gives Claude the show pane, search and history tools.

The Claude Code plugin

The screenshots are the real apps on made-up data. Go on with the features, the shortcuts or the configuration.
