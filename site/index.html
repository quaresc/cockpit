Install

Two commands in Claude Code

Setup asks what you want, writes your config and installs both halves.

  • macOS, with gh signed in and jq
  • herdr 0.9+ (with a Nerd Font), the Herdr app, or both
  • Your Claude Code connectors for tickets, CI and calendar, if any
claude 
> /plugin install cockpit --marketplace quaresc/cockpit
> /cockpit:setup
# any time later
> /cockpit:doctor

/cockpit:doctor checks every part and fixes what is broken.

FAQ

Questions

Do I need API tokens?

No. GitHub goes through your gh login, and tickets, CI and meetings come from the Claude Code connectors you already have, through one hidden, idle Claude session the hub keeps.

A Linear key, a CircleCI token or your calendar's secret iCal address are optional: with them the hub fetches that data itself.

What does it cost?

cockpit is free and MIT-licensed. Its Claude features run on your own Claude Code plan: recaps on haiku, meeting briefs, and routines, which take a weekly budget. Each one can be turned off.

The hidden session that reads your connectors sits idle at its prompt and spends no tokens.

Does it work without the Herdr app?

Yes. The herdr half works alone in your terminal, the Herdr app half works alone, and both can run at once on the same hub. Setup wires whichever you have.

Is my data sent anywhere?

Not to cockpit: there is no cockpit server. The hub runs on your Mac, listens only on 127.0.0.1 with a token, and keeps its state in ~/.cache/cockpit.

It talks to GitHub, your ticket and CI tools and your calendar as you, and Claude features go through your own Claude Code. Search over past sessions uses a small model, downloaded once and run locally.
