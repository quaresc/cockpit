cockpit

Your Claude Code agents, beside their ticket, PR, CI and deploy.

Plus your inbox, runbooks, to-dos, meetings, releases and routines, and one palette over all of it.

Herdr app Terminal

Install

In a Claude Code session:

/plugin install cockpit --marketplace quaresc/cockpit
/cockpit:setup

Setup asks what you want and installs both halves. /cockpit:doctor checks everything. Needs macOS, gh signed in and jq.

Two ways to run it

Herdr app

Drawn natively in the Herdr desktop app: Home, sidebar, every app as a view.

Terminal

In herdr: a sidebar, a footer and pinned spaces beside your agents.

Both share the same hub and data, so they can run at once.
