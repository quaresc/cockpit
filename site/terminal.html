Herdr TUI

cockpit in herdr: what each agent works on, beside it.

Sidebar

Each agent’s task, branch, ticket, CI and page. Red on failing CI.

Footer

One click to the ticket, PR, deploy, preview and every page the conversation cites.

Pinned spaces

Inbox, runbook, to-do, meetings, and opt-in monitor and routines, one key each.

Show and E2E

Charts, tables and diffs in a pane beside the agent; the agent tests its page in a browser beside it.

Palette

prefix+space over any pane: tickets, PRs, runbook steps, meetings, history and past sessions.

Keys

prefix + spacePalette
prefix + i t a d u m o yInbox, terminal, actions, to-do, runbook, meetings, monitor, routines
prefix + fThe page beside the agent, in your browser
prefix + shift+aEvery agent
j k · Enter · /Move · main action · filter, in every app
