Herdr TUI

cockpit, in your terminal

A plugin for herdr: what each agent works on, right beside it. /cockpit:setup installs it.

Install Keys

What's in it

  • SidebarEach agent's task, branch, ticket, CI and page. Red on failing CI.
  • FooterOne click to the ticket, PR, deploy, preview and every page the conversation cites.
  • Pinned spacesInbox, runbook, to-do, meetings, and opt-in monitor and routines, one key each.
  • Show panesCharts, tables and diffs beside the agent; comment a diff and send it back as one review.
  • BlueprintThe plan the agent keeps current, drawn as a flowchart in its pane.
  • E2E beside the agentThe agent tests its page in terminal-browser, next to the conversation.
  • Paletteprefix space over any pane: tickets, PRs, runbooks, meetings, history, past sessions.
  • Agents · Queue · ResumeEvery agent in one popup, prompts queued for a busy one, agents back after a restart.

Keys

In every app: j k move, Enter main action, / filter.
