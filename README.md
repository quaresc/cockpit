## Install

In a Claude Code session:

```
/plugin install cockpit --marketplace quaresc/cockpit
/cockpit:setup
```

Setup asks what you want and installs both halves; `/cockpit:doctor` checks everything. Needs macOS, `gh` signed in
and `jq`.
